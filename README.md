# Break-Even Desk

A ROAS calculator answers one question: below what return does a sale start losing money? Work it out here, then handle the costs most people quietly skip.

**Read the full page:** https://roas-calculator.github.io/

Break-even return on ad spend is the inverse of your margin, and almost everyone who gets it wrong got it wrong by using the product price instead of the money actually left after costs. Run the calculation with real numbers and it takes two minutes; run it with optimistic ones and it will tell you a losing campaign is fine. The caveat is that break-even is a floor and not a plan, because it ignores every fixed cost your business still has to cover. Once the arithmetic is settled, the harder question is what competitors are spending on and who is promoting them, which is what Reachara is built to show.
